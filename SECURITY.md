# Security Policy

## Supported versions

Security fixes are currently provided for the latest released version.

## Reporting a vulnerability

Please do not open public issues for vulnerabilities.

Use GitHub Security Advisories:

- https://github.com/TheCuriousApprentice/stars-dashboard/security/advisories/new

Include:

- affected version
- reproduction steps
- impact
- suggested mitigation (if known)

We will acknowledge reports and coordinate a fix and disclosure timeline.
